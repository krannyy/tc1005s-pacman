# tc1005s-pacman

Juego Pacman de freegames, modificado para la evidencia de TC1005S (Actividad 3).

Owner del repositorio: Jaime Samuel García Manzano (krannyy). Fork: Angel Barush (thenewbaru).

## Contenido
- `pacman.py`: el juego.
- `README.md`: este archivo.

## Cómo correrlo
```
pip install freegames
python3 pacman.py
```
Se mueve con las flechas del teclado.
